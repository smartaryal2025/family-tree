# अर्याल वंशावली (Aryal Family Tree) - V1.3

यो वेब एप्लिकेसन अर्याल परिवारको वंशावली सुरक्षित र व्यवस्थित राख्नको लागि निर्माण गरिएको हो। यसमा सदस्यहरूको विवरण, पारिवारिक हाँगाहरू, र पुस्ताहरूलाई अन्तरक्रियात्मक (Interactive) रूपमा हेर्न र सम्पादन गर्न सकिन्छ।

## मुख्य सुविधाहरू (Features)
- **सुरक्षित प्रणाली:** Supabase मार्फत युजर अथेन्टिकेसन र डेटाबेस व्यवस्थापन।
- **अन्तरक्रियात्मक रूख:** D3.js को प्रयोग गरी वंशावलीलाई सजिलै जुम, प्यान, र नेभिगेट गर्न मिल्ने।
- **प्रस्ताव प्रणाली (Approval Workflow):** साधारण सदस्यहरूले नयाँ सदस्य थप्न वा सम्पादन गर्न प्रस्ताव पठाउन सक्ने र एडमिनले स्वीकृत गरेपछि मात्र लाइभ हुने।
- **स्मार्ट सर्च:** देवनागरी वा रोमन (w/v/b लजिकसहित) दुवैबाट सजिलै सदस्य खोज्न मिल्ने।
- **Export/Print:** वंशावलीलाई PNG, PDF, वा Multi-page PDF को रूपमा डाउनलोड र प्रिन्ट गर्न मिल्ने।

## प्रविधिहरू (Tech Stack)
- Frontend: HTML5, CSS3, JavaScript (Vanilla), D3.js
- Backend/Database: Supabase (PostgreSQL)
- Tools: html2canvas, jsPDF
