# Contributing to Aryal Family Tree (अर्याल वंशावली)

Thank you for your interest in the Aryal Family Tree project! 

Please note that this is a **closed-source, proprietary project** developed and maintained exclusively by **Kishor Aryal (Utility Studio)**. 

## 🚫 Contribution Policy
At this time, we are **not** accepting open-source contributions, pull requests (PRs), or external code modifications to the core repository.

## 👪 Modifying Family Tree Data
If you are a family member and wish to add, update, or remove member details from the family tree:
1. Log in to the application using your account credentials.
2. Use the provided interface (Add/Edit buttons) on the website.
3. Submit your changes. They will be placed in a queue for administrative approval.
4. Once reviewed and approved by the admin, your changes will appear live on the family tree.

## 🐛 Bug Reports & Feature Requests
If you notice any technical bugs, errors in data visualization, or have a feature suggestion for future versions, please contact the administrator directly at:
**Email:** support@kishoraryal.com.np
